### 本轮踩坑（重要，可复用）
- **CSS 变量没落进 `:root`**：`--rule/--mono/--serif` 曾漏写，导致 `var(--rule)` 边框变无效（实测 `borderLeftWidth:0px`）、serif/mono 字体全部回退。**教训：改 CSS 变量后必须用 `getComputedStyle` 断言生效值，只看截图发现不了。**
- **headless driver 放 `/tmp` 会让相对路径错位**：`<img src="assets/...">` 解析到 `/tmp/shot/assets/`，`naturalWidth=0`（假失败）。解法：driver 的 `<head>` 里插 `<base href="file:///<dev>/index.html">`。
- **`--dump-dom` 不指定 `--window-size` 时默认窄屏**，会命中 820 断点（那里 `border-left:0`），一度误判成代码 bug。测响应式务必显式给窗口宽度。
- **模型读不了 PNG** → 改用「DOM 断言」做核验最可靠：`querySelector` 验结构 + `img.naturalWidth` 验图片真加载 + `getComputedStyle` 验滤镜/边框/尺寸。这套比截图管用，且能把结论写进 `<pre id="VERIFY">` 再用 `--dump-dom` 抓回来。
