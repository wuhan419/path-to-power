## POTUS 图像资产实做（已由"讨论"转入"动手"，Agent 模式）

- 用户拍板：把 12 个事件类型的"头版照片"做成**常驻组件**（按类型带图），并为 5 档难度各生成一张**政客头像**（按难度切换）。橡皮章保留。
- 关键风格裁定（用户原话"彩色图片,政治新闻常用到的那种 报纸爱用的"）：照片用**彩色政治新闻图**（报纸常用的那种），**不做黑白去色**。报纸/档案感改由版式语言撑——纸纹 + 红规线 + 旋转红橡皮章 + 等宽档案码（DOSSIER // EVENT NO.）+ 双线报头；照片本身可叠极淡棕褐做旧但**不全灰**。
- 12 类型清单（dev 现有图片，govt 目前退回 SVG 占位需补）：career 仕途(45) / media 舆论(28) / political 党务(23) / scandal 丑闻(17) / civil 民权(16) / foreign 外交(15) / finance 金钱(15) / crisis 危机(15) / govt 政务(12,缺) / shady 灰产(10) / general 综合(7) / romance 私情(1)。
- 5 难度政客头像人设（取自 dev/engine/view/create.js:21-29，真实游戏概念，非杜撰）：legendary 传奇=世家权贵(银发从容) / easy 简单=世家青年(精致自信) / normal 普通=商法精英(利落专业) / hard 困难=移民草根(坚韧风霜) / brutal 炼狱=蓝领工会(粗粝硬朗)。
