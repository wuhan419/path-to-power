## POTUS UI：悬浮 toast 被边栏裁切 → 改为全局 fixed 气泡层（v0.5.4）

用户截图：状态标签（.tag.hastip）的悬浮说明气泡在左栏右缘被切（文字只显示一半）。

### 根因
- 旧实现 `.hastip::after` 是 `position:absolute` 的伪元素，参考系是 `.hastip`。
- 但左/右边栏 `.col-left` / `.col-right` 是 `overflow:auto` 的滚动容器（`style.css:42-43`）。
- 绝对定位后代一旦超出滚动容器就会被**裁切**（不是 z-index 遮挡——是 overflow 裁剪）。气泡宽 240px、栏宽仅 250px 且标签常靠右，必然溢出被切。

### 修法（全局 fixed 气泡层）
- `style.css`：删掉 `.hastip::after` / `.hastip:hover::after`，保留 `.hastip` 虚线下划线；新增 `#tipbox{position:fixed;z-index:9999;...;pointer-events:none}`（`.on`=display:block）。z-index 9999 高于 `.modal`(20)。
- `render.js`：新增 `tipLayer()/showTip()/hideTip()/bindTooltip()`，`P.boot()` 里调用 `bindTooltip()`。
  - 事件委托 `mouseover/mouseout`（内容动态重渲染无需重绑），关键词 `[data-tip]`。
  - `#tipbox` 挂到 `document.body`——不是 `.col-left` 后代，**结构上免疫任何祖先 overflow 裁切**，恒在最顶层。
  - `showTip` 用 `getBoundingClientRect` 定位：横向夹在「所属栏」`.col-left/.col-right` 矩形内（找不到则退视口 ± 8px），保证不越出边栏；下方放不下自动翻到元素上方；`textContent` 写入，免疫注入。
  - 滚动/缩放时收起，避免错位。
- 验证过：body/#app/.grid/.panel 上**没有** transform/filter（唯一 `filter` 在 `.art-photo img`），故 `position:fixed` 相对视口生效、坐标正确。

### 测试
- `smoke-ui.js` 新增「悬浮说明气泡」段 6 项断言：悬停建 #tipbox、`.on`、文字取自 data-tip、**parentNode===body**、**不在 .col-left/.col-right 内**、mouseout 收起。→ 6/6 通过。
- 全量：180 项通过，唯一失败仍是预存「代价标签 $120k」漂移（与本改动无关）。
- 已 `package.sh` 发布到 dist（dist/engine/style.css 含 `#tipbox{position:fixed`、无 `hastip::after`；dist/engine/render.js 含 bindTooltip/tipLayer/tipbox）。

## POTUS UI：v0.5.4 三栏布局其实没生效（右栏掉到下面）→ 修 HTML 结构 + 收紧断点（v0.5.5）

用户实测反馈：「操作栏还是放到了下面……我希望是右侧」。上一版（v0.5.4）我以为三栏已完成，其实是**空欢喜**。

### 根因：startYear 模板多了一个 `</div>`（render.js:389）
- `P.startYear` 的模板字符串结尾写的是 `'</div></div></div><aside class="col-right" id="actbar"></aside></div>'`。
- 从 `.yearbar` 关闭开始数，正确只需 **2** 个 `</div>`（关 `.news` + 关 `#main`）就该输出 `<aside ... actbar>`；写成了 **3** 个，于是第 3 个把 `.grid` **提前闭合**。
- 结果：`<aside class="col-right" id="actbar">` 变成 `.grid` 的**兄弟**（`#app` 的直接子节点），作为 block 排在 grid 之后 → 整条操作链**掉到中间栏下面**。
- jsdom 诊断确认（/tmp/diag.js）：`.grid 子元素: ASIDE.col-left | DIV.#main`（只 2 个），`#actbar.parentNode = DIV#app`。
- 关键点：`#actbar` 只有这一处创建，其余屏幕全走 `actAppend()` 往 `#actbar` 塞内容 —— 结构一断，**所有**屏幕的操作都掉下去。

### 修法
- `render.js:389`：`'</div></div></div><aside...'` → `'</div></div><aside...'`（删掉多余的那个）。
- 修后诊断：`.grid 子元素: ASIDE.col-left | DIV.#main | ASIDE.col-right#actbar`，`#actbar.parentNode = DIV.grid` ✓，`.choices` 父元素也是 `#actbar` ✓。

### 顺带：三栏可用下界从 1150px 拉到 1000px（style.css:41-58）
- 旧 `@media(max-width:1150px)` 会把 `.col-right{grid-column:1/-1}` 掉到单独一行 —— 窗口一缩就复现「操作栏在下面」，与用户诉求相悖。
- `.grid` 列宽改可压缩：`minmax(200px,250px) minmax(0,1fr) minmax(280px,320px)`（最少 200+280+36+中栏 ≈ 1000px 仍三栏）。
- 断点 1150px → **1000px**。1280/1366 等常见笔记本窗口现在稳定三栏。

### 修掉一个我自己引入的回归：validate.js 崩溃
- v0.5.4 加的 `bindTooltip()` 里 `window.addEventListener(...)`；`tools/validate.js` 的宿主是 `global.window = global`（Node 全局对象，**没有 addEventListener**）、`document.body` 是裸对象（无 appendChild）。
- 现象：`validate.js` 直接 `× 加载内容包时崩溃：window.addEventListener is not a function`（smoke-ui 用 jsdom 有真实 DOM，所以掩盖了这个坑）。
- 修法：新增 `tipReady()` 探测真实 DOM（document.addEventListener / createElement / body.appendChild / window.addEventListener 全具备才为真）；`bindTooltip/hideTip/tipLayer/showTip` 全部前置守护，无 DOM 宿主直接跳过气泡绑定。

### 测试
- `smoke-ui.js` 新增「三栏布局」段 6 项断言：`.grid` 存在、**恰好 3 个子元素**、第 1/2/3 列分别是 `.col-left`/`#main`/`.col-right#actbar`、**`#actbar.parentNode === .grid`**。→ 6/6 通过。
- 全量 smoke-ui：186 项通过，唯一失败仍是预存「代价标签 $120k」漂移（与本改动无关）。
- node --check 通过；style.css 括号平衡 258/258。

### 教训
- **"看起来完成了" ≠ 完成**：上一版只跑了 jsdom 静态断言，没验结构；模板字符串里手写 `</div>` 极易多一个/少一个，必须用 DOM 结构断言兜住（这次补上了）。
- 引擎改动用 `validate.js`（裸 stub）与 `smoke-ui.js`（jsdom）**两套**跑，任何依赖 `window`/`document` 新 API 的代码都要在两套宿主下都能跑。

### 三件事（参数全部在 `content/01-config.js` 的 `balance.voterDynamic`）
1. **自然增减**（`core.js` 新增 `voterTargets/voterDrift`）：平静月均值回归
   `delta = (目标 − 当前) × monthly(0.05) × 轨道系数 × 声望系数`；目标 = 规模 × 8%/2%/4%。
   天然有界（挂机不满池）、超额支持会回落。调用点 `vignette.js → vignetteGrowth` 每月循环内，月卡会报数。
2. **事件成败自动增减**（`eventVoterDelta` + `withEventVoters`）：
   `base(规模×量级) × byOutcome(档位) × categoryMul(类型)`。不对称 —— 失败时反对者 +0.55、好感只 −0.35。
   三条让位规则：内容显式写 `voters` 以内容为准；改身位（tier/fall/hardEnd）不重复计；恋爱类系数 0.15。
   `effFinal` 同时用于"应用到状态"与"收益显示" → 账面与实际一致。
3. **反噬**（`voterEdge` ∈ [-1,1]）：`engine/dice.js` 的 `evalMod` 新增 `src:"voters"`；
   `computeP` 对晋升/连任类选项（`isContestChoice`：任一档位含 `tier+1`）**自动**附加 ±8%。
