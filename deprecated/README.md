# 废案 · 冻结归档（Deprecated / Frozen）

本文件夹存放**已确认完全无用、但为「将来可能重做那个年代」而保留**的内容，主要是 **pre-1980 死内容**。
游戏时钟从 1980 起、只向前走，这些早于 1980 的时代永不成为 `G.era`，其专属事件永不触发，
因此从**活树**（`dev/`，即真正加载 / 校验 / 打包 / 上线的内容）中移出，集中冻结于此。

## 冻结纪律（重要）

> **废案里的内容一律：不翻译、不改动、不重构、不参与校验、不打包。**
> 只做「原样封存」。除非有一天产品决定**正式重做那个年代**，才把对应文件取回 `dev/`、
> 恢复其 era 定义与 `index.html` 引用，届时再按当期规范修订。

在这之前，任何人都**不要**去动这里的文件——包括修正错别字、补翻译、调数值。保持冻结快照的
可复原性优先于一切整洁性。

## 为什么不放在 `dev/` 下

- `dev/index.html` 用 `<script src>` 白名单加载内容，校验器（`tools/validate.js`）也只读这份清单，
  所以本文件夹**不会被加载、不会被校验**。
- 打包脚本 `dev/tools/package.sh` 只把 `dev/` 同步进 `dist/`，本文件夹在其之外，**不会进构建产物、不会上线**。

## 内容清单

- `events/`：整包的 pre-1980 时代事件文件（各自自成一个时代的演示包），从清理前的提交原样恢复：
  - `100-era-1912.js`、`101-era-1929.js`、`102-era-1941.js`、`103-era-1954.js`、`104-era-1972.js`
  - `51-era-1960.js`（1960 肯尼迪「新边疆」）、`52-era-1974.js`（1974 水门「信任崩塌」）
- `snapshots/`：那些「宿主文件仍在活树服役、只是被摘除了其中的 pre-1980 片段」的**清理前整文件快照**，
  用于复原被摘走的那几段原文（零改动、以 git blob 原样导出）：
  - `20-eras.js` —— 含 1912–1974 全部 era 定义（锚点/压力/brief）与黑天鹅（blackswan）
  - `30-fillers.js` —— 1960 / 1974 的时代填充包
  - `08-vignettes.js` —— 「世相」槽位的 `wo60* / wo74*` 年代随笔
  - `54-era-waves.js` —— 6 个 pre-1980 浪潮事件（征兵 / 街头民权 / 输油管 / 泄密收买 / 巴士废校…）
  - `109-boon-fill.js` —— 5 张 pre-1980 boon 卡（1912 / 1929 / 1941 / 1954 / 1972）

## 复苏（真要重做那个年代时）

1. 从 `events/` 取回对应时代文件放入 `dev/content/events/`，在 `dev/index.html` 内容清单里加回 `<script src>`。
2. 从 `snapshots/20-eras.js` 恢复该时代的 era 定义块与其 blackswan 条目到 `dev/content/20-eras.js`。
3. 需要填充包 / 世相随笔 / 浪潮事件时，从对应 `snapshots/` 文件把该时代的片段贴回活树。
4. ~~若这些事件要进事件弧，参考 `snapshots/` 里旧 `arc` 节拍（或历史提交）补 `dev/content/11-arcs.js`。~~
   （**注**：事件弧主线已于 v0.10+ 停用——`index.html` 里 `11-arcs.js` 已注释、多支路主线整体砍掉；
   如未来重启事件弧玩法再另议，勿默认照此步操作。）
5. 跑 `node dev/tools/validate.js --games=8` 与 `node dev/tools/choice-audit.js` 通过后，再正常改动 / 翻译。
