事件卡里的「照片层」长什么样
content/09-photo-art.js · assets/events/

这个页面用真的引擎渲染器（P.artSVG）+ 真的样式表（engine/style.css）铺出 .news 事件卡，只是把正文换成了占位文字。改了照片或 CSS 之后刷新这里就能看到结果， 不用真的开局。
列宽与游戏内一致（#app 980px、.grid 1fr + 260px、.news 内边距 16px）。

全部类型（有照片出照片，没登记的照片安静退回程序化 SVG）

加载失败时的样子

照片文件缺失 / 改名时，卡片会自曝成「破图态」：把底下垫着的程序化 SVG 翻出来顶上。 下面这张是人为加上 .art-photo-broken 的效果。

怎么用

换图：把新图命名成 <类型 key>.jpg 覆盖 assets/events/ 下的同名文件即可，不用改代码。

单个事件换图：ev.photo = "my-shot.jpg"。

单个事件不要照片：ev.photo = false。

加新类型：在 content/05-categories.js 加一条 category， 在 content/09-photo-art.js 的 files 里加一行，再把图丢进 assets/events/。
