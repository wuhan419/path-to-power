## 这是什么

**权力之路** 是一款以**美国政治**为背景的生涯模拟器。你扮演一位从政者，跨越数十年、历经时代变迁，在一次次抉择中积累**声望、资金、派系好感与人脉**，也随时可能坠入**丑闻、调查、下野**乃至铁窗。

它的独特之处在于**引擎与内容彻底分离**：

- **引擎**（`dev/engine/`）只提供机制——掷骰、抽取、后果结算、时间推进、渲染。不含任何一句剧情或数值。
- **内容**（`dev/content/`）只声明数据——事件卡、时代、人物、结局。不含任何逻辑分支。

新增一个时代、一种事件类型、一个效果键，引擎会**自动接纳**，无需改动一行引擎代码。这让它可以像维基百科一样被社区持续扩充。

## 玩法概览

```
建角（时代 → 出身 → 出生州 → 天赋 → 起点 → 党派 → 姿态 → 定命一掷 + 自由点分配）
   → 一个月一回合 → 遭遇事件 → 做出选择 → 五档掷骰 → 后果传导 → 晋升 / 下野
   → 年终结算（三段式文学随笔）→ 终局评价（13 种结局）
```

- **一个月一回合，但并非月月有事。** 引擎按「时代压力 + 你自己惹上的麻烦」决定某月有几个事件档期、每个档期是什么分量。2008 年 9 月是压力 5，你会撞上雷曼那一周；平稳年份整年只有四五个档期。
- **三种资源即筹码**：资金 / 精力 / 人情。选项可以标价（付不起就变灰），也可以在判定前自己**下注**（砸钱和精力抬高胜算，花人情换一次「重投取优」）。
- **第四种筹码——把柄**：走灰色路线能攒下"胁迫本钱"。它不是存款，是**易腐的一次性武器**。
- **历史是有名字的**：专栏作家、工会头目、掮客、牧师……人脉是常驻 NPC，第一次照面即"认识"，此后积累好感，好感够高会主动为你打开某些选项。
- **出生州是地形**：深红州的共和党人顺风起步、同州的民主党人却是逆风——但少数派的同情让你在基层更好使。
- **升职要熬年头**：每个晋升事件都带"在位时长"门槛，坐够月份机会才会来。

## 核心系统设计

> 这是本项目相对同类文字游戏最硬核的三点设计。详细契约见 [`docs/CONTENT-SCHEMA.md`](docs/CONTENT-SCHEMA.md)。

### 1. 事件三值性（机遇 / 风险 / 威胁）

每张事件卡都属于三种"情绪基调"之一，每个档期**独立掷一类**，类与类互不挤占（有了好运不挡坏事）：

| 三值性 | 徽标 | 语义 |
|---|---|---|
| **boon** | 🟢 机遇 | 净收益是下限——即使掷骰最差，也只是"少赚"，不会转盈为亏。 |
| **risk** | 🟡 风险 | 要么给一个无风险保底选项，要么提供博一下的高波动——风险越大幅度越大。 |
| **bane** | 🔴 威胁 | 默认净损，但靠高掷骰 / 高属性 / 花钱可以规避，甚至"化险为夷"变坏为好。 |

三值性语义在**引擎结算层**（`engine/scale.js` 的 `shapeByValence`）按卡片声明的意图**强制执行**——内容侧只需写"意图 + 系数"，引擎保证契约不被写歪。

### 2. 一切结合人物状态的动态判定

这是整个系统的**核心哲学**：**同一个事件、同一个选项，对不同处境的人，意义完全不同。** 判定分三层落在这条原则上：

| 问题 | 机制 | 结合的状态 |
|---|---|---|
| **该不该发生？** | `engine/when.js` 声明式条件（`era/tierMin/funMin/flags/after/scandalMin…`） | 职级、财富、派系、历史标记、人脉、在位时长 |
| **该不该有选项？** | `costBlock`/`reqBlock` 把付不起、不够格的选项**置灰并写明原因** + 保底兜底 | 金钱余额、声望、职级、把柄、是否认识某人 |
| **该花多大代价换多大收益？** | `engine/scale.js` 动态标尺 + `stakeFunPer` 动态汇率 | 职级（月薪）、主属性、事件本身的钱量级 |

### 3. 系数制经济（卡只存系数，结算时 × 人物标尺）

事件卡**不写绝对金额**，只写**系数**。抽中时才在结算瞬间把系数 × 当前人物的"标尺"翻译成绝对值：

```
钱的收益 = 系数 × (职位月薪 × 量级月数 × 属性系数 × 职级系数)
```

于是**同样一句"赚 0.5 份钱"，社区小兵拿到是几千块，州长拿到是几十万**——经济的"体感通胀"随生涯自动缩放，内容却只需维护一份系数。

投注的汇率同样是动态的（`per = min(√(身位锚 × 事件锚), 事件锚)`），既保证"小兵也投得起第一档"，又保证"绝不会让你为一笔 $50k 的收益去掏 $250k"。

## 快速开始

### 玩

直接用浏览器打开 **[`dev/index.html`](dev/index.html)**（或双击）。

要打包成独立分发给别人：

```bash
bash dev/tools/package.sh   # 一键发布：先自检，通过后刷新 dist/（把 dist/ 整个文件夹发出去即可）
```

### 开发 / 自检（零依赖）

```bash
# 改完必跑：语法 / 引用完整性 / 契约 / 300 局蒙特卡洛模拟
node dev/tools/validate.js

# 事件库结构审计（三值性覆盖 / flag 闭环 / 事件链 / 财富闸门）
node dev/tools/audit.js

# 可选：真 DOM 冒烟（需先装一次 jsdom）
cd ~/.workbuddy/binaries/node/workspace && npm install jsdom
NODE_PATH=~/.workbuddy/binaries/node/workspace/node_modules node dev/tools/smoke-ui.js
```

**改完代码一条命令搞定**：`bash dev/tools/package.sh`（先跑自检、全部通过后才刷新 dist）。只想自检用 `bash dev/tools/package.sh --check`。

## 项目结构

```
.
├── dev/          开发区：引擎 + 内容 + 工具（改代码在这里）
│   ├── engine/     引擎（稳定，改动需走契约审查）
│   ├── content/    内容（事件 / 时代 / 人物 / 结局，随便扩充）
│   ├── tools/      validate.js 一键校验 · audit.js 结构审计 · package.sh 打包
│   ├── assets/     事件配图照片
│   └── index.html  加载器 + 内容包清单（加内容只改这里的 <script src>）
├── dist/         可分发：双击即玩的游戏本体（生成物）
├── docs/         文档：开发指南 / 内容契约 / 写作简报
└── PRD_….md      产品需求文档
```

**唯一接口**：内容通过 `POTUS.define(kind, payload)` 注册，引擎自动接纳。

## 参与贡献

最欢迎的两种贡献，按上手难度排序：

1. **写事件卡**（门槛最低、最有价值）——内容可无限扩充而无需碰引擎。照着 `dev/content/events/50-era-2008.js` 抄格式即可。
2. **提美术 / 平衡 / 机制**——需要走引擎契约审查。

请先阅读 [`CONTRIBUTING.md`](CONTRIBUTING.md) 与 [`docs/DEVELOPMENT-GUIDE.md`](docs/DEVELOPMENT-GUIDE.md)。**提交前必须跑 `node dev/tools/validate.js` 全部通过。**

发现 bug、想提内容或机制上的想法，直接开 Issue，或写信到 **contact-via-issues**。
