## 这是什么

**权力之路** 是一款以**美国政治**为背景的生涯模拟器。你扮演一位从政者，跨越数十年、历经时代变迁，在一次次抉择中积累**声望、资金、人情、派系好感、人脉与选民**，也随时可能坠入**丑闻、调查、下野**乃至铁窗。

它的独特之处在于**引擎与内容彻底分离**：

- **引擎**（`dev/engine/`）只提供机制——掷骰、抽取、后果结算、时间推进、竞选分幕、渲染、双语覆盖。不含任何一句剧情或数值。
- **内容**（`dev/content/`）只声明数据——事件卡、时代、人物、结局、竞选链。不含任何逻辑分支。

新增一个时代、一种事件类型、一个效果键、一条竞选链，引擎会**自动接纳**，无需改动一行引擎代码。这让它可以像维基百科一样被社区持续扩充。

### 当前是一个可玩的 DEMO

- **开局起于 1980，一路打到 2025。** 建角极简——你只需选 **难度 + 姓名**（详见[快速开始](#快速开始)）。不再选"时代"：游戏是一条按绝对年月推进的连续时间轴，历史大事件**到点必发**。
- **入主白宫不再是即时结局**：当上总统只是记下「曾任总统」，牌局继续，直到 2025 终点年弹出**生涯成就结算**（按一生做到了哪一级授予称号，7 档生涯结局）。
- **胜利线仍是「联邦众议员」**：第一次踏进全国政治的中心舞台（权力阶梯第 7 格）是一枚明确的高光"登顶"里程碑——但游戏不结束，仍可继续冲击参议员、副总统乃至白宫（也可能半路被清算）。
- **10 级权力阶梯**（引擎内部 `tier 0..9`，界面显示"等级 1..10"）。

## 它好玩在哪（v0.12 · 死亡是常态）

- **树敌与清算**：高收益的选项同时给你攒下**仇家**——新闻界、党建制派、金主、政敌、情报/执法系统，五组各有仇恨值。恨到 25 有前哨战，恨到 55 就是**清算大戏：掷骰失败即死，无保底，且仇恨永不衰减**。结算屏会提醒你死得多有梗：「你和肯尼迪一样，脑洞大开」「你的竞选经理带着剩余资金去了巴哈马」。
- **学贷死亡螺旋**：普通/困难/炼狱开局背着 $65k / $42k / $28k 的学生贷款，单利计息、每年 1 月把欠息资本化，每月从结余里还；月供盖不住当月利息就是断供，连续断供触底就是**破产收场**——联邦破产法里人气最高的那一章。想喘口气可以花声望**申请缓交**（一次 6 个月、全局至多 24），在低层公职老老实实按时供款满 120 个月还能吃到 **PSLF 豁免**一笔勾销。世家（简单/传奇）不用还，那是别人家的人生。
- **投注按你的身位定价**：判定前可以砸钱抬高胜算、花人情换一次"重投取优"；一档 = 你这个位子月薪 × 事件的钱量级系数，**与你家底多少无关**——小兵投得起第一档，富豪只是押得起更多档（公式细节见 [DESIGN](docs/DESIGN.md)）。
- **入主白宫之后才真正开始逐月**（v0.12 #21 M1—M4 全量落地）：总统一职不再只是"薪水变高的大事件"——每月必排一条**白宫决策**（危机 / 立法 / 外交 / 人事四族轮转 · 24 张卡 · 每族另有 1 张只在第二届登场），并配一根会自己往下掉的**支持率**：它向自然水位回归、每月净流失，起手按声望与选民底气在 25—72 之间播种（名义起点 46），而立法与外交选项的胜率直接吃它。任期本身开始收账：第 14 月被打上门要**中期交代**，第 36 月必须决定**要不要寻求连任**——赢了你进入第二届（次任专属卡解锁），输了当晚承认败选、下野；支持率长期躺在危险线以下又带着丑闻，**弹劾条款**会自己送进这个月的档期（硬扛 / 切割 / 辞职三条路，都不判死）。干满第二届自动届满离任，离任那笔账（低支持率、丑闻、未结调查）会**直接喂进清算池**——退休后真的有人来算账。最后结算屏按白宫账本分档：干满两届且体面 = **S 档「干满两届的总统」**，守四年 = A，一路挨打 = B。
- **生活不是复读机**：单卡终身衰减——同一张事件卡这局演过一次，再被抽中的概率就越抽越稀；而同一张卡**重演时不再重复发属性**（钱照给、属性归零），刷点的路是死的。
- **到 2025 才算打完**：活得够久，看自己签下的每一条法律慢慢改变这个国家；活不够久，报纸会替你写好讣告。

## 快速开始

### 玩

直接用浏览器打开 **[`dev/index.html`](dev/index.html)**（或双击）；手机竖屏同样可玩。

要打包成独立分发给别人：

```bash
bash dev/tools/package.sh   # 一键发布：先自检，通过后刷新 dist/ 并打出 itch.io 上传包 path-to-power-v0.12.zip
```

`dist/` 整个文件夹发出去即可；根目录那个 zip 是给 itch.io 用的 —— **index.html 直接躺在压缩包根目录**（不套一层文件夹），
上传后勾「This file will be played in the browser」就能在网页里直接玩。zip 是产物、不入库，`--no-zip` 可跳过。

### 建角（demo 版）：三步向导 —— 难度 → 天赋抽卡 → 自由点

开局起于 **1980**（一条连续时间轴的起点），其余由代码自动/随机填。三步走完给个名字就上路：

| 难度 | 出身 | 可选天赋卡 | 额外底子（**不含任何属性**） |
|---|---|---|---|
| **传奇** | 政治世家 | 5 张 | 世家底子之外再叠：声望 +12、人情 +4、建制 +20、商业 +10 —— 最厚，还能挑最多牌 |
| **简单** | 政治世家 | 4 张 | 出身给建制 +30、声望 +8、人情 +2 —— 有人替你开好路 |
| **普通** | 商学院／法学院精英 | 3 张 | 商业 +40、人情 +2，但基层信任 -15；另有学贷 $65k |
| **困难** | 移民二代 | 2 张 | 基层 +20、建制 -20，全凭一股韧劲；学贷 $42k |
| **炼狱** | 蓝领工人 | 1 张 | 工会 +40、基层 +15、人情 +1，但商业 -25、声望 -6、建制 -10；学贷 $28k |

**难度 = 出身 + 能选几张天赋卡**，它**既不发钱也不发属性**：开局资金从 0 起步（唯一例外是随机起点「商界起手」自带一笔 $8k 本金——建角一次性资金的顶），三围全部从 0 起步，钱与属性各有各的入口（见下方[设计不变量清单](#设计不变量清单)）。出身/起点/州这一侧的一次性资金封顶 **$8k**（= 4 个自由点），卡池里最贵的钱卡是 $6k。
卡墙一次呈现 **12 张**、四档稀有度**逐位独立掷**（一周目 93/6/0.9/0，越往后蓝紫橙越容易露头）；**橙卡（命卡）从第 2 周目起进池**，一周目最多抽到紫；整面卡墙可**刷新 1 次**。
卡池用的是**另一把尺**（#40 重标）：**卡面 1 属性点 = $1k**，档位是 **白 +1/$1k ｜ 蓝 +3/$3k ｜ 紫 三围各+2（合计 6）/$6k ｜ 金 三围各+5（合计 15）/$15k**——白卡允许「+2 并别维 -1」这种净 +1 的写法。
这把尺**比建角的自由点尺小一个数量级**（1 自由点 = +10 属性 = $2k），一张金卡的属性面只有建角池的 13%：**卡池负责风味与特效（免死、大成功翻倍、健康衰减、派系与人情），成长预算留给自由点和事件卡**。
自由点一周目 **12 点**，每完成一个周目永久 **+1 点**，池子越玩越大；**单维可以一路点到 100**（10 点灌满一维）。
第 2 步的天赋页还常驻一个作弊码输入框：`woshishabiN` 把**本次建角**按第 N+1 周目的口径开局（自由点额度与高稀有概率一起抬，上限 10、可累加、不写存档）。

姓名留空默认为「汤米」。起点、党派、州、天赋都由代码填/掷——把选择集中到"这局走什么运"上。

### 设计不变量清单

这些是**当前版本承诺的硬口径**，改代码前先对照；绝大多数条目在 `dev/tools/validate.js` 里都有对应断言（跑一次 `node dev/tools/validate.js` 就知道有没有写歪），少数"内容卫生"类靠 `tools/audit.js` 与人工评审兜底。机制为什么这样设计的论述在 [`docs/DESIGN.md`](docs/DESIGN.md)，字段契约在 [`docs/CONTENT-SCHEMA.md`](docs/CONTENT-SCHEMA.md)。

- **属性只有两条入口**：建角自由点（1 点 = +10）与天赋卡池（**另一把更小的尺：1 属性点 = $1k**，档位 白1/蓝3/紫6/金15）。出身／起点／出生州／难度**一律不发魅力·智力·手腕**；隐藏的诚信（INTG）只能由选择涨落，建角阶段只减不增。
- **钱只有两条入口**：每月的账（工资−开销−学贷−利息）与事件卡（含下注）。平静月的"随笔"不再产生资金，`trackBonus` 里也不许出现 `fun`。开局那一次性本金另算，且被钉死在 4 个自由点以内。
- **同一张卡的属性只发一次**：可重复卡重演时长相照旧、钱照给，属性归零（`G.attrGiven` 记账）——刷点通道封死。
- **一年 2—6 件事**（#38）：`balance.pace.eventMax` 给**非固定四桶**（日常公务＋随机＋灰产＋竞选幕）立了年总闸，另有 `careerMax 2`／`yearRandomMax 1`／`grayMax 1` 各管一条桶——全生涯同一条尺，不是只管开局。**真实历史钉卡与总统在位期的白宫月决策不计入、也不被拦**（"到点必演"通道），竞选幕记账但从不被拦在半路。
- **开局两年再薄一档**：`balance.earlyCalm` 把前 24 个月的"有事概率 / 日常公务 / 随机与灰产年额度 / 单月档期"各下一道轻乘子（`0.8 / 0.6 / 0.5 / 只排一条`；额度那一道走 `floor`，1/年 × 0.5 即开局两年不给随机名额），出窗后完全中性。
- **四大类不许倒挂**：固定史实 ≥ 职业公务 ≥ 随机，且三条桶各自的年均 ≤ `pace` 对应额度。**年度额度才是事件总量的真闸门**，`activeChance` 只管"这个月有没有档期"。
- **一场竞选一个月最多推进一幕**：幕数不变、摊到更多月份，竞选不再挤爆日程。
- **每个事件必须有保底选项**：破产、声望打穿时也总有一个按钮能点（清算包刻意除外）。
- **精力、健康不上界面**：`ap` 退役、`hp` 只在后台结算，新内容不要写这两个键。
- **历史到点必发**：`fixed` 钉卡与多幕事件串永不占随机额度。
- **1980→2025 一条时间轴**：当上总统不是终局，2025 硬墙后才弹生涯结算（7 档称号）；死亡随时可来，仇恨永不衰减。

## 玩法概览

```
建角（三步向导：难度+姓名 → 天赋抽卡 → 自由点，开局起于 1980）
   → 一个月一回合 → 遭遇事件 → 做出选择 → 五档掷骰 → 后果传导 → 晋升 / 下野 / 被清算
   → 民选晋升触发「竞选链」：宣布 → 初选 → 筹款/辩论 → 摇摆 → 投票日
   → 跨年只做后台结算（老化 / 利息 / 丑闻消退 / 黑天鹅）→ 打到 2025 → 生涯成就结算（中途死亡则即时结局）
```

- **一个月一回合，但一年只摊 2—6 件事。** 引擎按「时代压力 + 你自己惹上的麻烦」决定某月有几个事件档期（**上限两条**）、每个档期是什么分量；**总量由年度额度守着**（日常公务＋随机＋灰产＋竞选幕四桶合计 ≤ `pace.eventMax`），真实历史钉卡与总统在位期的白宫月决策是"到点必演"、另计。**开局头两年另有一道轻冷静期**，比全局再薄一档。时代压力优先按**绝对年份**读连续时间轴（`worldline`）。
- **历史到点必发：** 关键历史节点不再靠抽取碰运气，而是钉在日历上——某年某月**必定发生**的大事件与**多幕固定事件串**（前奏→爆发→余波），错选/坏运会把你推向调查、丑闻乃至下野。
- **日常公务·选民经营：** 在任者的平静月会注入致悼词、剪彩、市政厅接待、预算听证一类选民服务小事，持续经营好感 / 死忠 / 反对三档人数——他们最终折算成晋升与竞选的胜算修正。
- **四种筹码**：资金 / 声望 / 人情 / 把柄。选项可以标价（付不起就变灰），也可以在判定前自己**下注**（砸钱抬高胜算，花人情换一次「重投取优」）。把柄是走灰色路线攒下的"胁迫本钱"——不是存款，是**易腐的一次性武器**。（精力、健康两资源已退役，不再上界面。）
- **历史是有名字的**：专栏作家、工会头目、掮客、牧师……人脉是常驻 NPC，第一次照面即"认识"，此后积累好感，好感够高会主动为你打开某些选项。
- **出生州是地形**：深红州的共和党人顺风起步、同州的民主党人却是逆风——但少数派的同情让你在基层更好使。
- **升职要熬年头**：每个晋升台阶都带"在位时长"门槛，坐够月份机会才会来。
- **升职那一刻有典礼窗**：层级只要往上走就盖一层庆典结算——十格阶梯标出走过多远、月薪/选区规模/死忠三行新旧对照、下一级还差几个月在位、本局第几次晋升。跳级会额外说明"被跳过的那几级没记下资历"，而**降级与下野刻意不弹**（只庆祝往上走）。出口只有「就任 →」一个按钮（机制见 [`docs/DESIGN.md`](docs/DESIGN.md) 核心系统一）。
- **中英双语**：顶栏一键切换，十屏界面与全部事件卡都有英文覆盖层；中文是原文、零词典文件（机制见 [`docs/I18N.md`](docs/I18N.md)）。
- **存档只存你自己的浏览器**：进度写入本机 `localStorage`，不上传任何服务器——多人访问同一网址各存各的、互不影响。换设备或想备份，用操作栏的「导出 / 导入」把存档存成一个文件带走即可。

## 竞选链：每一次民选都是一连串事件

在本作里，**一场选举不是一个按钮，而是一连串有起承转合的事件**。当你熬够资历、触发某一级民选台阶时，引擎会自动为你**开打一场竞选**——宣布 → 初选 → 造势/筹款/辩论 → 摇摆拉票 → 投票日，一幕一幕强制推进（**一个月最多推进一幕**），未到的幕谁也抽不走。每场竞选带一张小选情表（**选情 / 金库**）：**只有选情跌破闸门才当场崩盘**，金库只决定你买不买得起广告——钱退出了胜负手，投票日的胜率由 `P.ballotBase()` 按累计选情现推（选情 50 = 五五开）。灰色路线还能往选举里**投放把柄**：初选靶掷对手退赛、大选靶喂记者（干净利落，但会被翻出来反噬）。**层级只在最后一幕授予**，而**跨进总统级的那一步只认开票夜**：除了赢下大选，没有任何资历、捐款或派系操作能把你塞进白宫——非投票日来源的晋升会被拦下，只折成一点声望。基层 3 幕、州级 5 幕、联邦/大位 5 幕、总统 6 幕——越往上，路越长。

**到了州级以上，这四样筹码就是竞选的入场券**（不是可选项，而是"没有也能参加、机会渺茫；投了才打得起"）：广告轰炸、精准投放、地面拜票这类手段各有金库门槛，起步那点钱只够半波广告，剩下的靠筹款幕与每一幕的拨款一幕一幕挣；砸钱与花人情可以在判定前**加码**（资金 6%/档、押满 +42%，比日常事件更陡），而**投票日那一掷买不到**——钱只买声势。家底也真会写进起手选情：同一 persona，一贫如洗比押得上 8 档的人低 5 点，但再多钱也不白送第 6 点（软门槛，谁都能参选）。**等级 4—6 尤其吃这套**：这几级的入场家底约 **$7k—710k**、级别价 $3k—30k/档，恰好够押 1—2 档——不投照样能选，但一场州级竞选的投票日只开在 41%—60% 胜率，那半档火力往往就是分水岭。

> **实测口径**（80 局探针 `dev/tools/out/campres-probe.js` ＋ validate 的「#39 金库闸」面板）：州级以上六条链各有一道金库闸（`air_war` 20 / `targeted` 20 / `media_buy` 22 / `floor_push` 26 / `blanket` 24 / `swing_blanket` 34），而起步金库只给到闸值的一半（10/12/14/16/18/24）——差额靠投票日前 19 幕的定额拨款和三处筹款事件一幕一幕挣。于是这道闸真的会咬人：**带闸的选项开演 85 次、被金库拦下 19 次（22%，最紧的联邦链 50%）**，既不是空气也不是墙。种子选情的软门槛读数：同一个人、家底 0 / 8 档 / 80 档 / 8000 档 → **19 / 24 / 29 / 29**。落到投票日：州级链实测 **41%—60%** 胜率（基层 22%—36%，而**基层两链全程 0 个加码入口**——那一路本来就不卖筹码）。

> 引擎 `dev/engine/campaign.js`、链定义 `dev/content/61-campaigns.js`、各幕事件 `dev/content/events/65-campaign-acts.js`。机制细节见 [`docs/DESIGN.md`](docs/DESIGN.md)，字段契约见 [`docs/CONTENT-SCHEMA.md`](docs/CONTENT-SCHEMA.md) 的 campaign 节。

## 核心系统设计

> 相对同类文字游戏最硬核的几点，一屏速览；完整论述见 [`docs/DESIGN.md`](docs/DESIGN.md)，字段级契约见 [`docs/CONTENT-SCHEMA.md`](docs/CONTENT-SCHEMA.md)。

- **事件三值性（机遇 / 风险 / 威胁）**：每张卡属于 boon / risk / bane 之一，引擎在结算层**强制兑现**声明的意图——boon 最差也只是少赚，bane 可被高掷骰与花钱"化险为夷"；有了好运不挡坏事。
- **一切结合人物状态的动态判定**：同一个选项，对不同处境的人意义完全不同——发不发生看声明式条件（职级/财富/派系/flags/人脉/在位时长），选项灰不灰看代价与门槛，值多少钱看动态标尺。
- **系数制经济**：事件卡**不写绝对金额只写系数**，抽中时才 × 当前人物的标尺。同一句"赚 0.5 份钱"，社区小兵拿到是几千块，州长拿到是几十万——体感通胀随生涯自动缩放，内容只需维护一份系数。
- **动态投注汇率**：每档价码由 身位锚 × 事件锚 × 资金闸 **三锚立方根**合成（v0.12 起资金正式入场当闸门）——小兵投得起第一档，富豪敢为 big deal 押家底。公式与验证见 DESIGN，这里不展开数学。

## 项目结构

```
.
├── dev/          开发区：引擎 + 内容 + 工具（改代码在这里）
│   ├── engine/     引擎（稳定，改动需走契约审查）
│   │   └── view/     界面层：建角 / 顶栏 / 状态栏 / 舞台 / 行动栏
│   ├── content/    内容（事件 / 时代 / 人物 / 结局 / 竞选链，随便扩充）
│   │   ├── 61-campaigns.js            ← 9 条民选竞选链定义
│   │   ├── events/65-campaign-acts.js ← 竞选各幕事件
│   │   └── i18n/en/                   ← 英文覆盖层（镜像路径，原内容文件不动）
│   ├── tools/      validate · audit · choice-audit · text-audit · gen-manifest
│   │               · i18n-coverage · i18n-events · smoke-ui · package.sh …
│   ├── assets/     事件配图照片
│   └── index.html  加载器 + 内容包清单（清单由 gen-manifest 托管，勿手改）
├── dist/         可分发：双击即玩的游戏本体（生成物）
├── docs/         文档：设计理念 / 开发指南 / 内容契约 / i18n / 并行派活
└── deprecated/   废案冻结归档（pre-1980 七时代，不加载、不校验、不上线）
```

**唯一接口**：内容通过 `POTUS.define(kind, payload)` 注册，引擎自动接纳。

## 参与贡献

最欢迎的两种贡献，按上手难度排序：

1. **写事件卡**（门槛最低、最有价值）——内容可无限扩充而无需碰引擎。照着 `dev/content/events/50-era-2008.js` 抄格式即可。
2. **写/调竞选链**——在 `61-campaigns.js` 里加一条链、在 `65-campaign-acts.js` 里补幕事件；引擎不改一行。
3. **提美术 / 平衡 / 机制**——需要走引擎契约审查。

请先阅读 [`CONTRIBUTING.md`](CONTRIBUTING.md) 与 [`docs/DEVELOPMENT-GUIDE.md`](docs/DEVELOPMENT-GUIDE.md)。**提交前必须跑 `node dev/tools/validate.js` 全部通过。**

发现 bug、想提内容或机制上的想法，直接在仓库开 Issue。
