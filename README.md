# 🏛️ 权力之路 · 美国政治生涯模拟器

> 一个**纯前端、零依赖、零构建**的文字驱动政治生涯模拟 / 视觉小说——也带一点 **roguelike**：自 v0.12 起，**死亡是常态**。
> 从一个社区小兵起步，沿一条**从 1980 按年月推进、直到 2025 硬墙的连续时间轴**，在历史到点必发的大事件与日常经营里，一步一个脚印（或一次一次踩坑）往上爬。

## 这是什么

**权力之路** 是一款以**美国政治**为背景的生涯模拟器。你扮演一位从政者，跨越数十年、历经时代变迁，在一次次抉择中积累**声望、资金、人情、派系好感、人脉与选民**，也随时可能坠入**丑闻、调查、下野**乃至铁窗。

它的独特之处在于**引擎与内容彻底分离**：

- **引擎**（`dev/engine/`）只提供机制——掷骰、抽取、后果结算、时间推进、竞选分幕、渲染、双语覆盖。不含任何一句剧情或数值。
- **内容**（`dev/content/`）只声明数据——事件卡、时代、人物、结局、竞选链。不含任何逻辑分支。

新增一个时代、一种事件类型、一个效果键、一条竞选链，引擎会**自动接纳**，无需改动一行引擎代码。这让它可以像维基百科一样被社区持续扩充。

### 当前是一个可玩的 DEMO

- **开局起于 1980，一路打到 2025。** 建角极简——你只需选 **难度 + 姓名**（详见[快速开始](#快速开始)）。不再选"时代"：游戏是一条按绝对年月推进的连续时间轴，历史大事件**到点必发**。
- **入主白宫不再是即时结局**：当上总统只是记下「曾任总统」，牌局继续，直到 2025 终点年弹出**生涯成就结算**（按一生做到了哪一级授予称号，7 档生涯结局）。
- **胜利线仍是「联邦众议员」**：第一次踏进全国政治的中心舞台（权力阶梯第 7 格）是一枚明确的高光"登顶"里程碑——但游戏不结束，仍可继续冲击参议员、副总统乃至白宫（也可能半路被清算）。
- **10 级权力阶梯**（引擎内部 `tier 0..9`，界面显示"等级 1..10"）。

## 它好玩在哪（v0.12 · 死亡是常态）

- **树敌与清算**：高收益的选项同时给你攒下**仇家**——新闻界、党建制派、金主、政敌、情报/执法系统，五组各有仇恨值。恨到 25 有前哨战，恨到 55 就是**清算大戏：掷骰失败即死，无保底，且仇恨永不衰减**。结算屏会提醒你死得多有梗：「你和肯尼迪一样，脑洞大开」「你的竞选经理带着剩余资金去了巴哈马」。
- **学贷死亡螺旋**：普通/困难/炼狱开局背着 $65k / $42k / $28k 的学生贷款，每月从结余里还；连续断供触底就是**破产收场**——联邦破产法里人气最高的那一章。世家（简单/传奇）不用还，那是别人家的人生。
- **投注是一场资源豪赌**：判定前可以砸钱抬高胜算、花人情换一次"重投取优"；每档价码由**你的身位 × 事件的钱量级 × 你手里的现金**三个锚动态算出——前期投得起，后期投得狠，但绝不会让你为一笔小钱掏空家底（公式细节见 [DESIGN](docs/DESIGN.md)）。
- **生活不是复读机**：单卡终身衰减——同一张事件卡这局演过一次，再被抽中的概率就越抽越稀。
- **到 2025 才算打完**：活得够久，看自己签下的每一条法律慢慢改变这个国家；活不够久，报纸会替你写好讣告。

## 快速开始

### 玩

直接用浏览器打开 **[`dev/index.html`](dev/index.html)**（或双击）；手机竖屏同样可玩。

要打包成独立分发给别人：

```bash
bash dev/tools/package.sh   # 一键发布：先自检，通过后刷新 dist/（把 dist/ 整个文件夹发出去即可）
```

### 建角（demo 版）：只选难度 + 姓名

开局起于 **1980**（一条连续时间轴的起点），其余由代码自动/随机填。你只决定两件事：

| 难度 | 出身 | 开局条件 |
|---|---|---|
| **传奇** | 政治世家 | 资金 $3.0M · 声望 +15、人情 +6、全属性 +5 —— 含着金汤匙落地 |
| **简单** | 政治世家 | 资金 $1.2M · 建制人脉 +30、声望 +8 —— 有人替你开好路 |
| **普通** | 商学院／法学院精英 | 资金 $400k · 智力 +15，但基层不信任你；另有学贷 $65k |
| **困难** | 移民二代 | 白手起家 $0 · 基层 +20、建制 -20，全凭一股韧劲；学贷 $42k |
| **炼狱** | 蓝领工人 | 家无余财 $0 · 只有工会与基层，起步声望更低、建制更冷；学贷 $28k |

五档难度＝出身＋一笔开局资源增量（由易到难递减），全部叠在「刚毕业的穷小子」基础盘（资金 $10k）之上。姓名留空默认为「汤米」。起点、党派、州、天赋、四属性都由代码填/掷——把选择集中到"这局有多难"上，一键开局。

### 开发 / 自检（零依赖）

```bash
# 改完必跑：语法 / 引用完整性 / 契约 / 蒙特卡洛生涯模拟
node dev/tools/validate.js                  # 默认 20 局
node dev/tools/validate.js --games=300      # 全量平衡口径

# 事件库结构审计（三值性覆盖 / flag 闭环 / 事件链 / 财富闸门）
node dev/tools/audit.js
```

**改完代码一条命令搞定**：`bash dev/tools/package.sh`（先跑自检、全部通过后才刷新 dist）。只想自检用 `bash dev/tools/package.sh --check`。

## 玩法概览

```
建角（难度 + 姓名，开局起于 1980）
   → 一个月一回合 → 遭遇事件 → 做出选择 → 五档掷骰 → 后果传导 → 晋升 / 下野 / 被清算
   → 民选晋升触发「竞选链」：宣布 → 初选 → 筹款/辩论 → 摇摆 → 投票日
   → 年终结算（三段式文学随笔）→ 打到 2025 → 生涯成就结算（中途死亡则即时结局）
```

- **一个月一回合，但并非月月有事。** 引擎按「时代压力 + 你自己惹上的麻烦」决定某月有几个事件档期、每个档期是什么分量。时代压力优先按**绝对年份**读连续时间轴（`worldline`）。
- **历史到点必发：** 关键历史节点不再靠抽取碰运气，而是钉在日历上——某年某月**必定发生**的大事件与**多幕固定事件串**（前奏→爆发→余波），错选/坏运会把你推向调查、丑闻乃至下野。
- **日常公务·选民经营：** 在任者的平静月会注入致悼词、剪彩、市政厅接待、预算听证一类选民服务小事，持续经营好感 / 死忠 / 反对三档人数——他们最终折算成晋升与竞选的胜算修正。
- **四种筹码**：资金 / 声望 / 人情 / 把柄。选项可以标价（付不起就变灰），也可以在判定前自己**下注**（砸钱抬高胜算，花人情换一次「重投取优」）。把柄是走灰色路线攒下的"胁迫本钱"——不是存款，是**易腐的一次性武器**。（精力、健康两资源已退役，不再上界面。）
- **历史是有名字的**：专栏作家、工会头目、掮客、牧师……人脉是常驻 NPC，第一次照面即"认识"，此后积累好感，好感够高会主动为你打开某些选项。
- **出生州是地形**：深红州的共和党人顺风起步、同州的民主党人却是逆风——但少数派的同情让你在基层更好使。
- **升职要熬年头**：每个晋升台阶都带"在位时长"门槛，坐够月份机会才会来。
- **中英双语**：顶栏一键切换，十屏界面与全部事件卡都有英文覆盖层；中文是原文、零词典文件（机制见 [`docs/I18N.md`](docs/I18N.md)）。
- **存档只存你自己的浏览器**：进度写入本机 `localStorage`，不上传任何服务器——多人访问同一网址各存各的、互不影响。换设备或想备份，用操作栏的「导出 / 导入」把存档存成一个文件带走即可。

## 竞选链：每一次民选都是一连串事件

在本作里，**一场选举不是一个按钮，而是一连串有起承转合的事件**。当你熬够资历、触发某一级民选台阶时，引擎会自动为你**开打一场竞选**——宣布 → 初选 → 造势/筹款/辩论 → 摇摆拉票 → 投票日，一幕一幕强制推进，未到的幕谁也抽不走。每场竞选带一张小选情表（**动量 / 金库**）：任一读数跌破闸门，竞选当场崩盘，不必硬撑到投票日；**层级只在最后一幕授予**。基层 3 幕、州级 4 幕、联邦/大位 5 幕、总统 6 幕——越往上，路越长。

> 引擎 `dev/engine/campaign.js`、链定义 `dev/content/61-campaigns.js`、各幕事件 `dev/content/events/65-campaign-acts.js`。机制细节见 [`docs/DESIGN.md`](docs/DESIGN.md)，字段契约见 [`docs/CONTENT-SCHEMA.md`](docs/CONTENT-SCHEMA.md) 的 campaign 节。

## 核心系统设计

> 相对同类文字游戏最硬核的几点，一屏速览；完整论述见 [`docs/DESIGN.md`](docs/DESIGN.md)，字段级契约见 [`docs/CONTENT-SCHEMA.md`](docs/CONTENT-SCHEMA.md)。

- **事件三值性（机遇 / 风险 / 威胁）**：每张卡属于 boon / risk / bane 之一，引擎在结算层**强制兑现**声明的意图——boon 最差也只是少赚，bane 可被高掷骰与花钱"化险为夷"；有了好运不挡坏事。
- **一切结合人物状态的动态判定**：同一个选项，对不同处境的人意义完全不同——发不发生看声明式条件（职级/财富/派系/flags/人脉/在位时长），选项灰不灰看代价与门槛，值多少钱看动态标尺。
- **系数制经济**：事件卡**不写绝对金额只写系数**，抽中时才 × 当前人物的标尺。同一句"赚 0.5 份钱"，社区小兵拿到是几千块，州长拿到是几十万——体感通胀随生涯自动缩放，内容只需维护一份系数。
- **动态投注汇率**：每档价码由 身位锚 × 事件锚 × 资金闸 **三锚立方根**合成（v0.12 起资金正式入场当闸门）——小兵投得起第一档，富豪敢为 big deal 押家底。公式与验证见 DESIGN，这里不展开数学。

## 项目结构

```
.
├── dev/          开发区：引擎 + 内容 + 工具（改代码在这里）
│   ├── engine/     引擎（稳定，改动需走契约审查）
│   │   └── view/     界面层：建角 / 顶栏 / 状态栏 / 舞台 / 行动栏
│   ├── content/    内容（事件 / 时代 / 人物 / 结局 / 竞选链，随便扩充）
│   │   ├── 61-campaigns.js            ← 9 条民选竞选链定义
│   │   ├── events/65-campaign-acts.js ← 竞选各幕事件
│   │   └── i18n/en/                   ← 英文覆盖层（镜像路径，原内容文件不动）
│   ├── tools/      validate · audit · choice-audit · text-audit · gen-manifest
│   │               · i18n-coverage · i18n-events · smoke-ui · package.sh …
│   ├── assets/     事件配图照片
│   └── index.html  加载器 + 内容包清单（清单由 gen-manifest 托管，勿手改）
├── dist/         可分发：双击即玩的游戏本体（生成物）
├── docs/         文档：设计理念 / 开发指南 / 内容契约 / i18n / 并行派活
└── deprecated/   废案冻结归档（pre-1980 七时代，不加载、不校验、不上线）
```

**唯一接口**：内容通过 `POTUS.define(kind, payload)` 注册，引擎自动接纳。

## 参与贡献

最欢迎的两种贡献，按上手难度排序：

1. **写事件卡**（门槛最低、最有价值）——内容可无限扩充而无需碰引擎。照着 `dev/content/events/50-era-2008.js` 抄格式即可。
2. **写/调竞选链**——在 `61-campaigns.js` 里加一条链、在 `65-campaign-acts.js` 里补幕事件；引擎不改一行。
3. **提美术 / 平衡 / 机制**——需要走引擎契约审查。

请先阅读 [`CONTRIBUTING.md`](CONTRIBUTING.md) 与 [`docs/DEVELOPMENT-GUIDE.md`](docs/DEVELOPMENT-GUIDE.md)。**提交前必须跑 `node dev/tools/validate.js` 全部通过。**

发现 bug、想提内容或机制上的想法，直接在仓库开 Issue。
