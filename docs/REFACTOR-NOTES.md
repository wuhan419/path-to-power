## 0. 已落地的修复

### 0.1 晋升事件"错位一档"

**症状**：晋升事件的标题与它真正带来的层级跃迁不一致——例如标题写"竞选州参议员"、实际效果却是"州长升总统"。

**根因**：线性晋升事件 `prog_*` 的 `tierMax` 被写成了**目的层级**（区间 `tierMin = 源`、`tierMax = 目的`）。由于 `tierMin/tierMax` 是对**玩家当前层级**做的包含式区间过滤（见 `when.js`：`tierMin ≤ 当前tier ≤ tierMax`），玩家在"目的层级"时该事件仍会被抽中，其 `tier:+1` 再把玩家往上顶一层，于是叙事（讲的是升到目的层级）与真实落点（比目的层级还高一层）错开一档。

**修复**：把线性 `prog_*` 事件的 `tierMax` 收窄到**源层级**（`tierMin == tierMax == 源层级`），事件只在它该触发的那一层出现。

| 事件 | 叙事（源→目的） | 修复前窗口 | 修复后窗口 |
|---|---|---|---|
| prog_council | 第一次上选票 T0→T1 | 0–1 | 0–0 |
| prog_state | 州议会 T1→T2 | 1–2 | 1–1 |
| prog_federal | 联邦众议员 T2→T3 | 2–3 | 2–2 |
| prog_senate | 州长/参议员 T3→T4 | 3–4 | 3–3 |
| prog_president | 总统大选 T4→T5 | 4–5 | 4–4 |

**关键安全性**：`effects.js` 里 `tier` 的夹取用的是 `balance` 的全局上下界（`b.tierMin/b.tierMax`），**不是事件自身的 `tierMax`**。所以收窄事件的 `tierMax` 只缩小它的"抽取窗口"，不会挡住晋升本身。

**验证**：`validate.js --games=60` 全绿；`smoke-ui` 零新增回归（其中 2 个 cost 断言在改动前即失败，源于 dyn 事件在测试中未经 `realize` 展开，与本修复无关）。

**尚未处理**：委任/名人/操盘/财富轨的里程碑事件（`prog_appoint/kingmaker/magnate/star`）仍是宽区间（如 2–4），属于轨道内里程碑，暂不动，留待 Campaign 重构一并审视。

- **🟢 真·减法（便宜，内容改动 <15 处）**：删 精力 ap、健康 hp、把柄 lev；删 死派系 宗教/情报。

## 2. 工作流 B：Campaign 事件串子系统

### 2.1 定位

在 `arc`（主线：只加权、不硬塞、可无疾而终）与 `ev.after`（事件链：局部机械前情）、`era.scheduled`（定点事件）之外，新增第三种语义——**campaign：强制度更高、严格分幕、可中途失败退出的连续事件串**。总统竞选是它的第一个用例。

### 2.2 定案

- **形态**：独立 `campaign` 子系统（不是 `arc` 的扩展）。
- **推进**：仍在月历里抽，但活跃期把"下一幕事件"强加权到近乎必出，**未来幕 gated 不可抽**（保证不跳幕）。
- **失败**：由**累计指标（meters）跌破阈值**触发，新增 `FAILED` 终态（区别于 `arc` 的 `faded` 淡出）。
- **层级授予**：`tier` 只由链的**末幕（大选）成功**授予；链入口（宣战/初选）不带 `tier:+1`。
- **与 A 耦合**：campaign 的 meters 直接复用减法后的新骨架（声望 / 资金 / 人情 / 派系）。因此 **A 先落地，B 建在其上**。

### 2.3 状态模型（草案）

```
G.campaign = { id, stageIdx, since, meters:{...}, status }
G.campaignLog = [ { id, from, to, status } ]   // status: active / done / failed / abandoned
```

### 2.4 内容 schema（草案）

`POTUS.define("campaign", { <id>: { gate, stages:[{ event, maxMonths, metersDelta(按结局), abortBelow }], failWhen } })`

### 2.5 待用户输入（未决项，以陈述句记录）

- **待定 B-1**：总统竞选链的具体阶段清单与各幕 meters 曲线。参考骨架：党内初选 → 首场辩论 → 路演/筹款 → 电视辩论 → 摇摆州与票仓拉票 → 利益交换 → 大选（公投）。
- **待定 B-2**：meters 的具体集合与各自失败阈值。候选三条：党内代表票 delegates、竞选金库 chest、势头 momentum（+ 大选选举人票 electoral）。
- **待定 B-3**：适用范围。除总统外，弹劾 / 继任 / 商业帝国等是否也走 campaign；做统一抽象还是总统专属。
- **待定 B-4**：`prog_president` 重构为链末幕后，`arc_ladder` / `arc_anointed` 的"总统大选"最后一幕改为链入口。
