## v0.12.3 · 2026-09-28 —— 底色是一路走出来的 ＋ 学贷撤回 65k ＋ 第一眼英文

四项，两支开发分支合到一处（`dev/presidency-settlement` ＋ `dev/loan-flat`）。

### ① #43 政治底色：从"建角选一个"改成"选择攒出来"

- **玩家侧**：建角不再问你的立场。四档底色（建制派 / 民粹派 / 进步派 / 保守派）由选项往
  `counters.creed_<档>` 记账，每次结算后引擎取 argmax 并过 `balance.creed{min:3, lead:2}` 双闸，
  谁都没攒起来就沉回建制派（"没掀过桌子的人就是党内的人"）。**可以改换门庭**，顶栏光谱跟着变。
- **配套一条快线**：T7—T9 九处「容易赢、狠狠结仇」的煽动选项——65-campaign-acts 六处
  （点名党机器 / 指控猎巫 / 烧金主席 / 清算演说 / 往死里打辩论 / 压轴集会）＋ 147 白宫停摆绕开党鞭
  ＋ 153 连任抢挑战者的火 ＋ 154 中期把助选开成控诉大会。成功当场大涨选情与铁杆票仓，代价是仇恨。
- **为什么这样定价**：200 局探针（`tools/out/incite-probe.js`）——第 9 / 18 / 27 / 36 次点火的死局率
  **17.5% → 40.5% → 58.5% → 77.5%**，首次清算平均落在第 7.8 次；对照"前哨战按时低头泄压"的局
  **0.5%**。所以这不是一条白拿的快线，是一条**看得见坡度**的快线：想安稳升官走平衡线，想赌就一路点火到被清算。
- **删掉的东西**：`setStance` 效果键（直接写 `G.stance` 会被下次结算覆盖，留着就是陷阱）、
  `arc.js` 把 stance 移出"建角定死"的 PERM 名单、`wingOutsider`/`wingShort` 两个顶栏词条。
  旧档 `G.stance === "outsider"` 就近迁进 `populist`，**`SAVE_FORMAT` 不升**，v0.12 系存档照旧续玩。

### ② 属性上限口径拆开 ＋ 声望满格不再作废

- **上限**：100 是【建角加点】的顶，**不是【属性】的顶**。旧口径三处一起夹 0—100，顶格人物在建角页第
  3 步看到"打底+自由点+卡加成=106"而落地只有 100 —— 正是 #37② 禁的那类账面两张皮。现卡面加成与
  局内成长只夹下限 0、不设上顶；平静月被动成长 `vignette.attrCap` 88 → **100**（收口到玩家自己点得满的高度）。
  代价已知：判定加成 `(属性−50)/100 × w` 随属性线性走，100→1.20、115→1.26 —— 幅度小是因为内容增量本来就小。
- **声望**：20 局实测（seed 20260927）生涯月 **11.5%** 停在 100、正向声望 **18.2%**（941/5160 点）被上限
  静默吃掉，最饱和一局 40.3% 的月份顶格；但中位局首次触顶在第 293 个月、终局=100 只 3/20 ——
  是**长线顺风局的专属问题**，不是全局通胀。所以不抬 100 这把尺（`req.rep` 展开、支持率播种、
  `voterDrift` 共用它，抬顶＝重标整条选举曲线），改成顶后折算：
  1 点溢出 = 当前选区规模 × `balance.repOverflow.warmShare`（0.0004）个好感选民 + 一条日志。
  选 `warm` 是因为它天然有界，会被 `voterDynamic.monthly` 均值回归抽回该层级目标位——**买一段顺风，不是永久复利**。
- **复测**：顶格后又掷出的 941.5 点全部折成 1,309,662 个好感选民（10/20 局碰过顶），静默归零 = 0；
  顶格月占比、层级分布、终局分布与折算前逐字相同——折算没推歪任何一条分布。
- 落地：`effects.js` 新增唯一入口 `P.addRep(v, G, silent)`（返回 `{gained, over, warm}`），
  `rep` handler、两处资历闸折抵、随笔被动声望全走它（顺手修掉随笔记原始点数的虚报）；
  validate 四条新闸 + 源码级 `G.rep =` allowlist。

### ③ 默认语言改英文

新玩家第一眼必须是 English（主要发在外网）。只翻"没有偏好时兜哪一边"：`DEFAULT_LANG` zh → en，
中文退回玩家显式选择（标题屏/顶栏开关 → `localStorage.potus_lang` → 整页重载）。
**「默认」≠「主语言」**——内容原文与 `P.t` 的中文兜底串一字未动，中文侧照旧零词典。
代价是缺译从边角升成默认门面，所以 `i18n-coverage` / `i18n-events` 从此算首屏闸（本版实测 en 逐屏中文 **0%**）。
顺带把校验工具的语言由隐式改显式：`validate.js` 不写 `--lang` 时钉 zh、`text-audit.js` / `smoke-ui.js` 同 ——
默认一翻就有整类断言被悄悄换语言跑，双语门禁会退化成同语言两遍。

### ④ #42 学贷定稿：三档拉平 $65k（**撤回 v0.12.2 的 90k / 115k**）

上一版把方向掰成"越难背得越多"（65k / 90k / 115k）——**方向对、幅度错**，而且是没校准就发了出去的一档。
同 seed 30 局实测本金敏感度：65k → 破产 47%、85k → 70%、105k → 73%，且 85k 起 `retire_high` / `kingmaker`
这类**生涯结局整批归零**。根因不是"还不够难"，是这根轴**本身没有余量**：65k 这一档的"每局最长连续断供"
中位已经顶到 **19/20 月**（中位那局离破产差一个月），再抬只是把整条分布推过断供闸。

定稿 = **三档一律 $65k**：方向矛盾（越难背得越轻）消失，谁都不再被加码，"越难越苦"全部交给
`picks`（炼狱 1 / 困难 2 / 普通 3 张天赋卡）与出身底子两根轴。方向闸措辞随之从「越难背得越多」
改成「**不许随难度递减**」（同值合法）。

一条测量学事实顺带查清，记在这里免得下次再踩：**`validate.js --diff=X` 里"难度"只等于学贷本金** ——
harness 在 `P.CSEL` 里把 origin/talent 都预先点了，`picks` 那根轴从没被走到。拿它当"整体难度手感"会双重计罚。
