# 设计理念

这份文档记录我们**为什么这样设计**《权力之路》——它的定位、叙事基调，以及几个关键取舍背后的理由。
它不讲字段怎么写、机制怎么调（那些在 [`CONTENT-SCHEMA.md`](CONTENT-SCHEMA.md)、[`STAKE-ECONOMY.md`](STAKE-ECONOMY.md)、[`VOTER-SYSTEM.md`](VOTER-SYSTEM.md)、[`EVENT-WRITING-BRIEF.md`](EVENT-WRITING-BRIEF.md) 里），只留下"后来者需要知道的初衷"。

---

## 一句话定位

《人生重开模拟器》的随机性 +《十字军之王》的关系网与阴谋 +《纸牌屋》的道德灰度。
玩家扮演一个刚起步的美国年轻人，在真实的历史浪潮里用数十年时间，沿**任意一条**能通向权力的路径往上爬——或者摔下去。

核心体验不是"赢"，而是**"你为了权力愿意走哪条路、弄脏到什么程度，以及历史会怎么记住你"**。

---

## 设计支柱：可能性优先

我们做的不是一条"实习生 → 总统"的线性养成，而是一张**可能性网**。开局的可辨识组合来自三个正交维度的相乘：

| 维度 | 取值 | 决定什么 |
|---|---|---|
| 起点路径 | 直接入行 / 专业 / 名人 / NGO / 商界 / 幕僚 | 开局资源包与初始可选项层级 |
| 晋升轨道 | 选举 / 委任 / 名人 / 操盘 / 财富 | 怎么往上爬、哪种属性值钱、谁会帮你 |
| 党派姿态 | 民主 / 共和 / 独立 × 建制 / 反建制 | 能否调用党内机器，还是必须对抗它 |

所有轨道最终收敛到同一套**权力层级 T0–T5**，但抵达方式与解锁的终局各不相同。因此终局不止"总统"一种——幕后操盘手、说客之王、媒体大亨、大法官，都是完整的"通关"。

这套组合空间是内容规模的骨架，也是引擎与内容分离得以成立的前提：正因为路线是"声明出来的组合"而不是"写死的分支"，社区才能持续加内容而不动引擎。

## 叙事基调

**第二人称 + 冷峻新闻体。** 事件描述像新闻报道，选项像内心盘算，结果像事后复盘。全程不评判玩家，只呈现后果。

参考坐标：

| 来源 | 我们借鉴什么 |
|---|---|
| 《纸牌屋》 | 权力博弈的冷峻逻辑、盟友背叛的常态化 |
| 《大空头》《华尔街之狼》 | 把复杂金融翻译成"普通人看得懂的贪欲"，金融作为权力工具 |
| 《白宫风云》 | 理想主义与体制摩擦，作为高诚信路线的叙事支撑 |
| 《教父》 | 人情网络、恩惠与债务的长期偿还（对应游戏内"人情点"） |
| 《了不起的盖茨比》《美国往事》 | 时代氛围、暴富幻梦与幻灭 |
| 《十字军之王 3》 | 派系好感、丑闻与暗杀、角色特质 |
| 《极乐迪斯科》 | 内心独白式的属性检定 |

## 关键取舍与理由

### 每个事件必须有一个保底选项

每个档期 2–4 个选项，其中至少一个既无资源代价、也无前置条件——即**你破产了、声望被打穿了，也总有一个按钮能点**。

理由：玩家的钱会被事件花光、声望会被打下去，而"所有选项都变灰"意味着游戏直接卡死、只能读档。保底不是敷衍的"什么都不做"，它是一类正式设计（拼体力、拼时间、低成功率高风险），往往比"有钱怎么办"更有戏——**没钱的人怎么办，才是政治故事的核心**。引擎另留一根保险丝：万一内容写漏导致全部变灰，会强行放行一个并标注；但校验脚本会把违规事件直接报出来，不允许依赖保险丝。

### 投注同时受"加成上限"和"余额"限制

D&D 式下注不能出现"资源花了但收益不再增长"。精力、资金各自的加成都有硬上限，扣款前引擎会再夹一次——**界面就算被改坏，也不会多扣玩家的资源**。具体汇率为什么是动态的、怎么验证，见 [`STAKE-ECONOMY.md`](STAKE-ECONOMY.md)。

### 诚信（INTG）是路线约束，不是"越高越好"

高诚信让人难以被攻击、吸引理想主义者，但会**永久锁死一部分高效选项**（没法收黑钱、没法造谣、没法背叛盟友）。我们刻意把它做成方向选择，而不是数值高低。

### 终局评分维度互相冲突

评分同时看权力高度、道德账本、实际影响、人际与时代评价。我们故意让它们**此消彼长**：最高权力的路几乎必然压低道德账本。终局会同时呈现"权力分数"和"道德分数"，让玩家自己咀嚼，而不是给一个单一"好坏"结论。

### 美术：文字即美术，零依赖优先

核心视觉是**排版**——严肃衬线字体、克制的动画、精心设计的留白，比堆图片更有格调，也换来体积小、秒开、无版权风险、无网络依赖。事件配图走程序化 SVG 兜底（`事件专属 art → 类型默认 art → 引擎兜底`），保证**任何新事件都一定有图**；真历史照片只是可选增强，不进入主链路。

### 技术栈：原生 HTML/CSS/JS，零构建

这个游戏的复杂度在内容与状态机，不在 UI。加构建工具只会带来依赖和维护成本，而单文件（`index.html` + 一堆 `<script src>`）可以直接发给任何人、双击即玩。这也是"引擎/内容分离 + 清单式加载"能落地的根因，详见 [`DEVELOPMENT-GUIDE.md`](DEVELOPMENT-GUIDE.md)。

## 创作边界

本作以**美国政治为唯一背景**，地缘描写不把任何非美国政治实体描绘为独立主权国家，也不触及中国政治（平台合规硬约束）。真实历史事件、人物与机构的引入以**公开事实为底线**，不凭空捏造在世人物尚未公开、无法查证的内容；相关描写仅用于叙事与模拟，不代表任何官方立场。
